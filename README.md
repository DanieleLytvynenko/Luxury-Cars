# 🚗 LUXURY.CAR — Premium Car Rental Landing Page

A fully responsive premium car rental website built with pure HTML, CSS and vanilla JavaScript. Features a dark luxury design, dynamic car catalog with brand filtering, booking form with validation, and smooth animations.

## Features

- **Dark luxury design** — bold typography, yellow accent, smooth animations
- **Fully responsive** — works on mobile, tablet and desktop
- **Brand filter** — filter cars by Lamborghini, Ferrari, BMW, Porsche and more
- **Dynamic catalog** — car data loaded from JSON via Fetch API
- **Booking form** — with client-side validation and success modal
- **Mobile burger menu** — animated, full-screen navigation
- **Accessible** — semantic HTML, ARIA labels, keyboard navigation
- **No frameworks** — pure Vanilla JS, zero dependencies

## Tech Stack

- HTML5 (semantic markup)
- CSS3 (Flexbox, Grid, CSS variables, clamp(), animations)
- JavaScript ES6+ (async/await, Fetch API, DOM manipulation)
- Google Fonts (Bebas Neue + Montserrat)

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/DanieleLytvynenko/luxury-cars.git
   ```

2. Open `index.html` in your browser — no build tools or dependencies required.
